# Daintree Store

Daintree is a full-stack e-commerce web application currently under active development. It simulates a real online store, including product browsing, search functionality, and user authentication.

## Tech Stack
- Frontend: React, JavaScript, HTML, CSS  
- Backend: Node.js, Express  
- Database: SQL  

## Features
- Product browsing and search  
- User authentication (register/login)  
- Dynamic data via API integration
